מטרת המסך

מסך שקוף שמסביר למשתמש מה התפקיד שלו ומה הוא יכול ולא יכול לעשות, כדי להפחית פניות 'למה אין לי גישה'.

מה נבנה בגרסה 1

נכלל (v1-lite)
תצוגת קריאה: התפקיד וטבלת ההרשאות.
נדחה
פירוט כיתות וילדים; כפתור פנייה למנהל.

שאר המפרט בעמוד הוא תיאור המסך המלא. כשיש סתירה, ההיקף של v1-lite הוא שקובע מה נבנה עכשיו.

רכיבים משותפים

המסך נבנה רק מהרכיבים המשותפים שב-src/components/ui. לכל רכיב יש הסבר, props ודוגמת קוד במדריך הרכיבים המשותפים. מה שלא ברשימה ולא במדריך: שואלות את ראשת הצוות לפני שבונות.

PageHeader ◇ Table Modal Alert Button ◇

◇ = מחובר בפריים ב-Figma: לוחצות עליו ורואות את שורת הקוד בחלונית הימנית. בלי ◇ = עדיין מצויר ב-Figma: רואות אותו ב-Storybook (npm run storybook), עם קישור במדריך.

  • המסגרת (סרגל עליון, תפריט צד ולשוניות המודול) מגיעה מ-AppShell. לא בונים אותה במסך.
  • מצבי טעינה, ריק ושגיאה: לפי הטבלה במדריך (Table, EmptyState, StateViews).

המודול בשרת

תיקייה מוצעת: src/modules/mypermissions, שנוצרת עם npm run new:module -- mypermission --screen A05.

אין למסך אוסף פרטי, ולכן מוחקות את model.ts שנוצר ומייבאות מהליבה.

שם הבדיקה ב-authorize: authorize('A05', 'read') ל-GET, ו-'write' לכתיבה.
